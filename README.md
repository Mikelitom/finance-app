
# Couple Finance

Offline-first personal and shared finance application.

## Platforms

- iOS (Primary)
- Linux
- Windows
- macOS

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- IndexedDB + Dexie
- PWA

### Backend
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy

## Repository Structure

- `apps/api`: Backend API
- `apps/web`: Frontend PWA
- `docs`: Architecture and specifications
- `infra`: Infrastructure

## Development

This project is developed as a monorepo.

Backend and frontend can be developed
independently while sharing API contracts.
